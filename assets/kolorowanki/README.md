# Kolorowanki — pochodzenie

Pięć oryginalnych projektów wygenerowanych wbudowanym narzędziem image_gen. Nie są reprodukcjami obrazów Ewy Miłek. PNG zachowano bez dodatkowej kompresji i zmiany rozdzielczości.

Założenia promptów: pionowa karta do wydruku A4, czarne kontury mandali i białe pola do kolorowania, subtelne pastelowe narożniki, tytuł, podpis „Ewa Miłek • ewamilek.pl” oraz informacja o pomocy AI.

Motywy kolejnych projektów:
- Rozkwit: lotos i liście.
- Spokój: fale i krople wody.
- Przemiana: osiem motyli.
- Radość: promienie słońca.
- Marzenia: gwiazdy i księżyce.

Druk: dopasowanie do A4; nie deklarujemy rozdzielczości 300 dpi. Nie udostępniono dokładnego identyfikatora modelu ani rozliczenia generowania.
